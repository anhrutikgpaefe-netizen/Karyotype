# Karyotype：多物种染色体保守连锁与重排比较

只用基因在染色体上的归属和顺序，比较多个物种（12 种哺乳类、8 种鱼类及外群）的染色体：哪条对哪条，哪些基因块始终连锁，
对应区段内基因顺序是否一致，不一致时是谁变了、变化是不是几个物种共有的。
所有脚本只依赖 Python 标准库（旧的 Excel 解析脚本除外，见 `archive/`）。

> **状态：探索性研究。** 对应关系只按基因名判断，不是经过验证的直系同源；结果没有经过同行评议。
> 解读结果前请先读最后的[局限](#局限)。

## 功能

项目回答四个由浅入深的问题：

| 问题 | 做法 | 入口 | 结果位置 |
|---|---|---|---|
| 两个物种的染色体怎么对应？共有多少基因？ | 统计每对染色体共有的基因数，生成热图、对应列表和明细表 | `web/chrom_pairs.py`、`web/build_chrom_page.py` | `web/` |
| 哪些基因块在所有物种里始终在同一条染色体上？ | 按基因在各物种的染色体组合划分互不重叠的连锁单元 | `units/units.py` | `units/` |
| 对应区段内基因顺序是否一致？谁变了、是否共有？ | 区段内两两检验共线，按物种树推断祖先排列，逐个相邻基因对推断断点，并做显著性检验 | `compare_orderN.py`、`test_shared_breaks.py` | `order5/` |
| 哪些融合或裂变候选可能是几个物种共有？ | 以各物种为锚点找保守模块，再列出事件候选（探索性） | `compare8_v5.py` | 根目录 `mammal8_v5_*` |

输入是每个物种一份基因表，输出是 TSV 表格和可以单独打开的 HTML 报告。

## 数据与物种

物种登记在 [web/species.tsv](web/species.tsv)。

- **哺乳类（12 种）**：须鲸 `Balae`、河马 `Hippo`、大象 `elephant`、儒艮 `Dugong`、海牛 `inunguis`、猫 `cat`、狐獴 `meerkat`、
  马 `Equus`、黑猩猩 `hxx`、人 `homo`、穿山甲 `Manis`、假吸血蝠 `Megaderma`
- **鱼类及外群（8 种，`fish/`）**：矛尾鱼 `Latimeria`、棱皮龟 `coriacea`、雀鳝 `gar`，以及 `banmasha`、`jingsha`、`zhusha`、
  `xiaoyao`、`bsnake`（后五个的物种名待确认）

| 文件 | 内容 |
|---|---|
| `<物种>.txt` | 两列：基因名、染色体 |
| `<物种>_positions.tsv` | Chromosome、Symbol、Start、End、Strand、GeneID、Gene_order |

两者都由 [fish/parse_ncbi_v2.py](fish/parse_ncbi_v2.py) 从 NCBI 下载的基因表（`*_dataset.tsv`）解析得到：

```
python fish/parse_ncbi_v2.py Manis_dataset.tsv Manis order5/pos
```

原始基因表体积大，没有放进仓库，见 `.gitignore`。黑猩猩（`hxx`）目前只有染色体归属，没有坐标，所以不参与基因顺序比较。

## 快速开始

### 1. 染色体对应关系表（`web/`）

两个物种间，每对染色体共有多少个基因；三个物种时，可以查看两个物种对应到参照物种同一条染色体的那些染色体彼此是否同源。

```
cd web
python chrom_pairs.py species.tsv pairs.json                      # 计算所有物种的基因级数据
python build_chrom_page.py pairs.json chromosome_correspondence.html   # 生成网页
python chrom_pairs.py species.tsv --pair coriacea gar --min 20 --out coriacea_gar.tsv   # 单个物种对的 Excel 式表格
```

加物种：在 `species.tsv` 里加一行，再运行前两条命令。网页是单个 HTML 文件，带 `--artifact` 参数可生成适合发布的版本。

### 2. 基因顺序比较（`compare_orderN.py`，结果在 `order5/`）

在对应的染色体片段内检验各物种的基因顺序是否共线，并结合物种树判断哪一侧是衍生排列。唯一使用坐标的分析。

```
python compare_orderN.py --species A=A_positions.tsv --species B=B_positions.tsv ... \
    --tree "(elephant,(homo,((Hippo,Balae),Equus,(meerkat,cat))))" --out order5/mammal7j
python test_shared_breaks.py order5/mammal7j --tree "(...)" --contrast "Equus:Balae,Hippo" --out order5/mammal7j_test
python report_multigroup.py order5/mammal7j --tree "(...)"
python report_shared_events.py --out order5/shared_events.html order5/mammal7j order5/mammal8 order5/mammal8bat
```

给没有坐标文件的物种传入 `两列的 .txt`，它只参与划分区段，不参与顺序比较。物种树用括号写法，同一括号里逗号分隔的多个物种表示未解析的多分支。

### 3. 连锁单元（`units/`）

按基因在所有物种中的染色体组合划分互不重叠的单元，没有锚点物种。

```
python units/units.py --species NAME=FILE ... --min-genes 30 --min-present 5 --out mammal8
```

配套：`sensitivity.py`（阈值敏感性）、`unit_events.py`、`shared_pair.py`、`map_v4.py`、`plot_units.py`；带 `_e` 的是加入马之后的版本。

### 4. 连锁模块与事件候选（`compare8_v5.py`）——探索性

以各物种轮流为锚点找保守模块，再列出"两个模块在部分物种同染色体、在其他物种分开"的候选。
候选之间互相重叠，不等于独立的重排事件；结论以第 2、3 项为准。
用法见 [compare8_使用说明.txt](compare8_使用说明.txt)。

当前版本是 v5（输出 `mammal8_v5_*`）。根目录还留着第一版（`mammal8_*`）和 v4（`mammal8_v4_*`）的输出，
因为 `units/unit_events.py`、`units/map_v4.py` 和 `plot_submodule_events.py` 要读它们。

### 5. 鱼类及外群（`fish/`）

上述方法在 8 个鱼类及外群物种上的版本：`compare8_v2.py`、`compare3_v2.py`、`compare_order3.py`、
`report_one_differs.py`、`polarize_one_differs.py`。

## 方法要点

**区段内基因顺序比较**是当前最完整的一条线：

1. **共有基因**：每个物种里只出现在一条染色体、且有坐标的基因；丢弃 `LOC` 开头的占位名、线粒体和未定位序列。
2. **对应区段**：各物种所在染色体的组合相同、基因数不少于 30 的一组共有基因算一个区段，区段互不重叠，没有锚点物种。
3. **共线检验**：区段内每一对物种，把基因按坐标排序后比较名次。名次相差不超过 3 算同一块，少于 5 个基因的零星错位当噪声；
   只剩一块（整段反向也算）即共线。
4. **排列分组**：两两共线的物种归为一组，每组是一种"排列"，按组数分为全部一致、一个不同、两个不同……
5. **推断祖先排列**：两组时看哪一侧在物种树上是一个分支；三组以上按物种树做简约法，求最少变化次数和祖先候选。
6. **断点连接推断**：每对相邻基因算一个连接，判断它在各物种里是否保留，再在树上分别推断祖先状态，统计每个物种的衍生断点和共有衍生断点。
7. **显著性检验**：同一区段内携带相同衍生状态的物种集合合并成一个事件；保持每个事件的携带物种数和每个物种的事件总数不变，
   随机交换 20000 次，比较两个物种同时携带的事件数与随机预期（单侧 p，BH 校正）。

## 主要结果

下面的数字都来自仓库里的输出文件，均为探索性结果。

### 连锁单元（8 个哺乳类，`units/`）

- `mammal8e` 得到 **66 个单元，共 15,728 个基因**，每个单元在 8 个物种里都有对应。
- X 染色体在 8 个物种里整体构成一个单元（`U03`，599 个基因），其余单元分布在常染色体上。
- 阈值敏感性：`--min-genes` 取 10 到 100、`--min-present` 取 4 到 8，共 25 组参数，分单元结果与基准的调整兰德指数最低为 0.954。
- 单元层面的事件候选 250 个（`units/mammal8e_unit_events.tsv`）。

### 基因顺序比较（哺乳类，`order5/`）

| 数据 | 区段数 | 全部一致 | 一个不同 | 分两组 | 多种排列 | 全部互异 | 阈值边缘 |
|---|---|---|---|---|---|---|---|
| 7 物种（`mammal7j`） | 71 | 16 | 14 | 2 | 34 | 3 | 2 |
| 8 物种，加穿山甲（`mammal8`） | 80 | 12 | 20 | 2 | 43 | 1 | 2 |
| 8 物种，加蝙蝠（`mammal8bat`） | 87 | 18 | 17 | 3 | 44 | 3 | 2 |

- **只有两对公认的姐妹物种显著共有衍生断点**：须鲸与河马（观测 28 个事件，随机预期 12.5，q = 0.0005），猫与狐獴（28 对 8.8，q = 0.0005）。
  加入穿山甲、蝙蝠后这两对仍显著，q 约 0.0007。
- **马、穿山甲、蝙蝠、人与其他类群之间没有超出随机预期的共有衍生断点**（校正后 q 均不显著）。
  马与鲸或河马共有的事件为 11 对随机 14.0，与猫或狐獴共有的为 9 对 12.1。这与奇蹄目、食肉目、翼手目、鳞甲目分化较快相符，
  但样本很小，不能当作这些类群关系的证据，也不能当作反证。
- **祖先排列有相当一部分无法确定，主因在树根**：7 物种的 53 个有分歧区段中，25 个能确定，18 个"仅根处不确定"，10 个因其他原因不确定；
  极性不确定的 87 个相邻基因对里 73 个（约 84%）是"唯一的外群大象与其余物种不同"这类树根两侧的差异。
  只有一个外群时这类差异在原理上分不开，改用断点连接推断后可确定的区段数几乎不变，要解决得加入更远的外群。
- 观察到同一位置被多个物种分别使用的断点：一个 78 个基因的区段里，河马、大象、穿山甲三个物种的断点落在同一个约 5 个基因的范围内，
  按整段排列会被拆成好几种"排列"。

### 基因顺序比较（鱼类，`fish/order3/`）

- 三种鲨（`banmasha`、`jingsha`、`zhusha`）：42 个区段中全部一致 8、一个不同 21、三者互不一致 11、阈值边缘 2；"一个不同"里 `zhusha` 占 14 个、`jingsha` 7 个。
- 跨类群的三物种组合（`bsnake`/`coriacea`/`gar`、`coriacea`/`gar`/`Latimeria`、`xiaoyao`/`bsnake`/`Latimeria`）：每组 45 至 48 个区段里有 37 个三者互不一致，顺序大多已打散。
- 鱼类模块与事件候选（`fish8_v2`）：104 个模块、587 个事件候选。

### 鸟类（`birds/`，进行中）

- GFF 来自 NCBI RefSeq：游隼 `bFalPer1.pri`（23 条染色体）、灰冠鹤 `bBalReg1.pri`（37 条染色体）、红腿叫鹤 `ASM69053v1`。
  红腿叫鹤这份是旧组装，没有染色体，12,585 条序列里每条最多 9 个基因，不能用于染色体或基因顺序分析，正在等新版组装。
- 游隼与灰冠鹤：共有单拷贝基因 12,553 个，12,476 个落在 35 个对应区段里；35 个区段只有 1 个共线，把窗口放到 40、噪声长度放到 20 后仍有 26 个有重排。
  染色体对应（阈值 20 个基因）：一对一 8 条，游隼一条对应灰冠鹤多条 8 条，游隼多条对应灰冠鹤同一条 4 条。
  只有两个物种，无法判断是哪一个发生了变化。
- 用法：`python birds/gff_to_positions.py 文件.gff.gz 物种名 birds/pos`，`python birds/compare_pair.py A=… B=… --out birds/A_B`。

### 染色体对应表（`web/`）

覆盖 20 个物种的两两对应，例如海牛与儒艮的染色体基本一对一（热图呈对角线），矛尾鱼与棱皮龟则存在多条染色体合并或分散的对应。
可在 `web/chromosome_correspondence.html` 里交互查看。

## 意义

- **方法上**：给出一条从 NCBI 基因表出发、只用标准库、可以复现的染色体比较流程，覆盖对应表、连锁单元、区段内顺序比较、
  断点推断和显著性检验，输出都是可以直接打开或发布的 HTML。
- **生物学上**：
  - 连锁单元给出哺乳类里始终连锁的基因块（如整个 X 染色体），可作为比较核型的参照。
  - 把区段内的重排当作稀有基因组变化，检验类群关系：目前它只支持两对公认的姐妹物种，对争议类群没有提供支持。
  - 量化了"为什么祖先排列判不出来"：大部分原因是外群太少，指明了需要补哪些物种。
  - 列出的区段和事件候选，可作为进一步用序列比对或更严格同源关系核查的起点。
- **边界**：这是探索性分析，结论不能直接作为发表结论，需要先补足下面"下一步"里的工作。

## 局限

- 基因的对应只看基因名是否相同，不是经过验证的直系同源；物种越远，漏掉和错配的基因越多。
- 只使用在一个物种里只出现在一条染色体上的基因名。
- 不同物种的染色体编号互相独立，数字相同不代表同源。
- 模块和事件候选不给出融合或裂变的方向；只有基因顺序比较会借助物种树推断衍生的一侧。
- 物种树只定了部分关系（马、蝙蝠、穿山甲与两对姐妹物种的关系当作未解析），部分判断依赖这些假设。
- 共线和断点的判定用了固定的名次窗口（3）和噪声长度（5），小区段（几十个基因）的结论把握有限。
- 显著性检验的零模型不含物种树，事件在同一区段内按携带集合合并，不保证彼此独立。
- 鱼类 8 个物种里 5 个物种名还没有确认；各物种的基因组组装和注释版本不同，没有做质量控制。

## 下一步

1. 用 OrthoFinder 或 NCBI 同源基因关系替换基因名对应。
2. 对每个基因组做组装和注释质量检查，剔除不可靠的断点区域。
3. 用模拟数据（在树上随机造倒位、易位）验证方法能否找回真实的共有断点。
4. 加入更多物种：奇蹄目、翼手目的其他物种，以及异关节总目或有袋类外群，以解决树根处的不确定。
5. 补齐黑猩猩等物种的坐标，并确认鱼类物种名。
6. 与已发表的祖先染色体重建和 Laurasiatheria 关系研究逐项对照。
