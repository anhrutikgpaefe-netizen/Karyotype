Karyotype：多物种染色体保守连锁与重排比较

只用基因在染色体上的归属和顺序，比较多个物种的染色体：哪条对哪条，哪些基因块始终连锁，对应区段内基因顺序是否一致，不一致时是谁变了、是不是几个物种共有。

GitHub：anhrutikgpaefe-netizen/Karyotype · 详细文字说明见 README.md · 本页内容与 README 对应，结果更新后请同步修改

探索性研究 · 按基因名对应，不是验证过的直系同源

一页回顾

  • 数据：12 种哺乳类、8 种鱼类及外群，另有 3 种鸟（游隼、灰冠鹤、红腿叫鹤）。每个物种一份基因表，由 NCBI 的基因表或 GFF 解析得到。
  • 最稳的发现：基因顺序比较里，只有两对公认的姐妹物种（须鲸与河马、猫与狐獴）显著共有衍生断点；马、穿山甲、蝙蝠、人与其他类群之间没有超出随机的共有断点。
  • 最大的限制：判断“谁发生了变化”需要外群；只有一个外群时，树根两侧的差异在原理上分不清，约 84% 的极性不确定连接属于这一类。
  • 最新进展：鸟类部分，游隼与灰冠鹤已完成；红腿叫鹤现有的组装太碎，在等新版本。
  • 脚本：全部只用 Python 标准库，仓库已用 git 管理并推送到 GitHub，今后的版本更新直接在仓库里做，不再新建 _v2 之类的副本。

功能

项目回答四个由浅入深的问题。

1 染色体怎么对应

统计两个物种每对染色体共有的基因数，生成热图、对应列表和明细表。
web/chrom_pairs.py、web/build_chrom_page.py

2 哪些基因块始终连锁

按基因在所有物种里的染色体组合划分互不重叠的连锁单元，没有锚点物种。
units/units.py

3 区段内基因顺序是否一致

区段内两两检验共线，按物种树推断祖先排列，逐个相邻基因对推断断点，并做显著性检验。
compare_orderN.py、test_shared_breaks.py

4 哪些融合或裂变候选可能共有

以各物种为锚点找保守模块，列出事件候选（探索性，候选之间互相重叠）。
compare8_v5.py

输入是每个物种一份基因表，输出是 TSV 表格和可以单独打开的 HTML 报告。

方法流程：区段内基因顺序比较

  1. 共有基因：每个物种里只出现在一条染色体、且有坐标的基因；丢弃 LOC 开头的占位名、线粒体和未定位序列。
  2. 对应区段：各物种所在染色体组合相同、基因数不少于 30 的一组共有基因算一个区段，区段互不重叠。
  3. 共线检验：区段内每对物种按坐标排序比较名次；名次相差不超过 3 算同一块，少于 5 个基因的零星错位当噪声；只剩一块（整段反向也算）即共线。
  4. 排列分组：两两共线的物种归为一组，每组是一种排列，按组数分成全部一致、一个不同、两个不同等。
  5. 推断祖先排列：两组时看哪一侧在物种树上是一个分支；三组以上按物种树做简约法，求最少变化次数和祖先候选。
  6. 断点连接推断：每对相邻基因算一个连接，判断各物种是否保留，在树上分别推断祖先状态，统计衍生断点和共有衍生断点。
  7. 显著性检验：同一区段里携带相同衍生状态的物种集合合并为一个事件；保持每个事件的携带物种数和每个物种的事件总数不变，随机交换 20000 次，与随机预期比较（单侧 p，BH 校正）。

局限与下一步

局限

  • 基因的对应只看基因名，不是经过验证的直系同源；物种越远，漏掉和错配的基因越多。
  • 只使用在一个物种里只出现在一条染色体上的基因名；不同物种的染色体编号互相独立。
  • 物种树只定了部分关系，马、蝙蝠、穿山甲与两对姐妹物种的关系当作未解析。
  • 共线和断点判定用固定的名次窗口（3）和噪声长度（5），几十个基因的小区段结论把握有限。
  • 显著性检验的零模型不含物种树，事件在区段内按携带集合合并，不保证彼此独立。
  • 鱼类 8 个物种里 5 个物种名未确认；各物种组装和注释版本不同，没有做质量控制。

下一步

  1. 用 OrthoFinder 或 NCBI 同源基因关系替换基因名对应。
  2. 对每个基因组做组装和注释质量检查，剔除不可靠的断点区域。
  3. 用模拟数据验证方法能否找回真实的共有断点。
  4. 加入更多物种（奇蹄目、翼手目的其他物种，异关节总目或有袋类外群）以解决树根处的不确定。
  5. 补齐黑猩猩等物种的坐标，确认鱼类物种名；与已发表的祖先染色体重建对照。

常用命令

# GFF 转坐标表（NCBI RefSeq GFF3）
python birds/gff_to_positions.py 文件.gff.gz 物种名 birds/pos

# 染色体对应：Excel 式表格 / 网页
python web/chrom_pairs.py species.tsv --pair A B --min 20 --out A_B.tsv
python web/chrom_pairs.py species.tsv pairs.json
python web/build_chrom_page.py pairs.json out.html

# 三个及以上物种的区段内基因顺序比较，加显著性检验
python compare_orderN.py --species A=A_positions.tsv --species B=B_positions.tsv --species C=C_positions.tsv \
    --tree "(C,(A,B))" --out order5/demo
python test_shared_breaks.py order5/demo --tree "(C,(A,B))" --out order5/demo_test

物种树用括号写法，同一括号里逗号分隔的多个物种表示未解析的多分支。只有两个有坐标的物种时用 birds/compare_pair.py。
